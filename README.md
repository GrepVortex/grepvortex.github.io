# grepvortex.github.io

Wurzelseite für Google Search Console und als offizielle Homepage der Erweiterung.
Enthält den Verifikationstag und verlinkt auf die Projektseite:

- Projektseite: <https://grepvortex.github.io/dns64-browser-extension/>
- Quellen der Erweiterung: <https://github.com/GrepVortex/dns64-browser-extension>
- Chrome Web Store: <https://chromewebstore.google.com/detail/dns64-browser-extension/fnolfhpfonkjefmlbpcanncdnliadhpe>

Diese Seite ist absichtlich eigenständig (eigenes Favicon, keine Abhängigkeit zur Projektseite),
damit sie auch dann funktioniert, wenn dort gerade ein Build läuft.
